# Contributing to a paused research archive

Thank you for reviewing the records. **The research is paused; there is no active promise to support FiveM Linux or maintain a playable client.**

## Appropriate contributions

- Corrections to documentation, citations and source attribution.
- Reproducible public Windows/Wine API tests with non-proprietary fixtures.
- Clearly scoped, independently verifiable Wine compatibility findings.
- Reports of a broken local link or incorrect evidence interpretation.

## Not appropriate here

- Uploading official `Adhesive.dll`, GTA V assets, Rockstar/FiveM executables, copyrighted binaries or private crash dumps.
- Publishing access tokens, account identifiers, authentication tickets or raw user logs.
- Claiming a tested issue is solved merely because the crash is suppressed or a client UI loads.
- Providing or requesting disabled security functionality, fake authentication tickets or other protection bypasses.

## Before opening an issue or PR

1. Check [the documented blocker](https://github.com/feraskozx1-byte/Fivem-linux/issues/1), [the test matrix](docs/TEST_MATRIX.md) and [the FAQ](docs/FAQ.md).
2. State the **exact tested versions**, minimal setup, observations, expected behavior and limitations.
3. Separate reproductions from theories. Redact sensitive paths and identifiers.
4. Keep patches narrow and disclose which tests were actually run.

The GitHub issue template and PR template help keep research verifiable. Since this is a private repository, access to contribute may be limited.
