# Security and data-handling policy

This is a historical FiveM/Wine compatibility **research archive**, not a supported runtime.

## Safety and privacy

- Do **not** upload authentication tickets, bearer tokens, API keys, passwords, private keys, cookies, personal crash dumps, user profiles, saved login state or proprietary protection DLLs.
- Text source, debug traces and patches can also contain secrets. Automated scans are **heuristics**, not guarantees.
- If a secret has accidentally entered Git history, removing the visible file alone does not remove it from previous commits. Revoke/rotate exposed credentials and contact the repository owner privately.
- Do not execute archived probes/patches on a live gaming installation without independently reading their source; they were captured from controlled, version-specific investigations.

## Security reports

Avoid placing exploit details, live credentials or account data in public or even shared issues. Use a private channel already established with the repository owner. This repository does not advertise a security-response SLA or vulnerability bounty.

## Scope

The archive does not ship anti-cheat bypasses, fabricated game authentication or official/proprietary binaries. For the project status, see [README](README.md).
