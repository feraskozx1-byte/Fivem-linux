# Security, privacy and redistribution

This repository is intentionally **private** in the linked GitHub account. The author can choose to publish the curated documentation in the future, but must review every file first.

**Do not upload**:
- The official proprietary `adhesive.dll`, GTA V/FiveM game assets, Rockstar Launcher binaries or third-party copyrighted redistributions.
- `*.dmp`, `*.pdb`, live process memory, authentication tickets, `cfxTicket2` data, user access tokens, OAuth URLs with credentials, sessions, passwords or API keys.
- Wine prefixes, browser profiles, full system configuration or PSN/PS5 secrets.
- Gigabyte-sized compiled clients, generic caches, complete download directories or Windows VM disk images.

Even text logs can contain secrets or personal paths; do **not** import raw `*.log` by default. Curated excerpts and hash values are preferred.

Any local patches should target public, documented Windows compatibility behavior; the aim was to support original official security functions, **not** bypass them. A patch that only hides an error or bypasses validation is not counted as a solution.

**License:** Upstream source and third-party work remain under their own licenses. No new license to upstream proprietary binaries is conferred by this archive. Ask the owner before broad public redistribution.
