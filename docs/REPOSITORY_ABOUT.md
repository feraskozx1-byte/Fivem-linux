# GitHub repository About — recommended settings

The connected GitHub app currently supports reading/writing repository **files**, but not editing the sidebar **About**, topics, social-preview settings, visibility or archive status. The project owner can set these through the GitHub interface.

> Historical FiveM-on-Linux research archive: Wine/Proton, PS5 Ubuntu, CoreRT, Adhesive and NTDLL compatibility experiments. Paused; no working public-server support.

No external project website exists or is required. Leave the Website field blank, or use a link to [docs/INDEX.md](INDEX.md) if GitHub accepts the repository URL as the homepage.

## Suggested GitHub UI steps

1. Open the repository page.
2. Find **About** on the right; click the **gear icon**.
3. Paste the description and add the topics listed above; save.
4. For a social preview, navigate to **Settings → General → Social preview** and upload a manually reviewed PNG/JPG preview if desired. The repo includes [an SVG banner](../assets/banner.svg) suitable as a design reference.

**Keep Private** unless you have reviewed all imported text for personal data, tokens and third-party redistribution rights. Do not accidentally expose proprietary binary assets.
